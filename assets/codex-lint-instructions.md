## frontend 작업 마무리 검사

- `frontend/`의 코드나 lint 설정을 변경했다면, 최종 응답 전에 저장소 루트 기준 `frontend/` 디렉터리에서 `pnpm run lint`를 실행한다.
- `frontend/`의 포맷 설정 또는 포맷 대상 파일을 변경했다면 같은 디렉터리에서 `pnpm run format:check`를 실행한다.
- 검사 오류는 이번 작업과 관련된 범위에서 수정하고 다시 확인한다. 관련 없는 기존 오류는 임의로 대량 수정하지 않고 구분해 보고한다.
- 최종 응답에 실행한 검사와 결과를 적는다. 환경 문제 등으로 실행하지 못했다면 그 이유를 명시한다.
- 검사를 통과시키기 위한 무단 규칙 비활성화나 프로젝트 전체 자동 수정은 하지 않는다.
